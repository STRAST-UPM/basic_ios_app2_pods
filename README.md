# basic_app

## Descripción
`basic_app` es una aplicación iOS desarrollada en **Swift** que integra múltiples librerías. Se gestiona a través de **CocoaPods** para la administración de dependencias.

## Librerías Importadas
A continuación, se detallan las librerías utilizadas en la aplicación:

### Bases de Datos
- **Realm** → Base de datos móvil local y en la nube.
- **RealmSwift** → Implementación en Swift de Realm para un acceso más eficiente a bases de datos.

### Programación Reactiva
- **RxSwift** → Biblioteca de programación reactiva para trabajar con eventos asincrónicos.
- **SwiftAlgorithms** → Conjunto de algoritmos útiles optimizados para Swift.

### Gráficos y Animaciones
- **Lottie** → Biblioteca para reproducir animaciones en formato JSON exportadas desde After Effects.
- **DGCharts** → Biblioteca para la generación de gráficos y visualizaciones de datos en iOS.
- **Charts** → Extensión para gráficos interactivos en Swift.
